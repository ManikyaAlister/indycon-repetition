# indycon-repetition

This repository contains the data and analysis code for modelling how increasing numbers of sources affect participants' confidence (non-linear, Bayesian power-function models).

Note that due to the size of the output files, the analyses/output folder is empty, but this repository  should contain all of the code necessary to reproduce the output. 

**Key files**
- **evaluate-brms-modelling.qmd**: Project report and figures using the brms fits; reproduces main analyses and narratives in the manuscript.
- **analyses/**: Analysis scripts and utilities.
	- **fe-brms-modelling.R**: Scripts to fit fixed-effects (single-level) brms power-function models and save results.
	- **models.R**: Model definitions (non-linear formulae and priors) used by the brms fits.
	- **plot-fits.R**: Functions to plot model fits against observed data (used by the Quarto report).
	- **model-comparison.R**: Code that runs LOO/LOOIC comparisons across candidate models and summarizes results.
	- **priors.R** and **prior-baseline-comparison.R**: Prior specifications and checks comparing baseline priors.
	- **analyses/output/**: Saved model fit objects (`.Rdata`) and precomputed comparison tables/plots used for quick report rendering.
- **data/**: Raw and cleaned data used for modelling.
	- `experiment-1a/`, `experiment-1b/`, `experiment-2/`: Per-experiment cleaned CSVs and `.Rdata` objects under `clean/` and `derived/` subfolders.
	- **combine-1a-1b.R**: Script to combine experiment 1a and 1b datasets for pooled analyses.
- **plots/** and **analyses/plots/**: Plot outputs generated by the analysis scripts.
- **testing/**: Useful development scripts for exploring model choices and small-scale checks (e.g., `evaluate-best-function.R`, `test-functions.R`).
